# Calm Breath

A camera-based **adaptive breathing pacer** for relaxation. Most breathing apps
pick a pace and hope you can follow it. Calm Breath **measures your actual
breathing rate** with the [Presage SmartSpectra](https://smartspectra.presagetech.com/) SDK (optical measurement from your camera — nothing touches your skin), starts the pacer at *your* rate, and gently steps it down toward ~6 breaths per minute (resonance breathing), only slowing further when your measured breathing actually follows.

Built with Electron + `@smartspectra/node-sdk`. Entry for the
[Presage SmartSpectra SDK Challenge](https://dev.to/devteam/join-the-presage-smartspectra-sdk-challenge-3000-in-prizes-across-10-winners-1370).

> **Wellness demo, not a medical device.** Calm Breath does not diagnose,
> treat, or monitor any condition. See the disclaimer below.

## How it works

1. **Consent first.** The app explains exactly what the camera measures and
   what happens to the data. The camera turns on only after you press
   **Start session**, and a "camera on" indicator + Stop button stay visible.
2. **Baseline (45 s).** Breathe normally. Calm Breath reads your breathing
   rate and HRV (RMSSD) via SmartSpectra.
3. **Adaptive pacer (90 s).** An animated circle paces your breath, starting
   at your measured rate and stepping down toward 6 br/min. The target only
   drops when your measured breathing follows it — the app never drags you
   faster than your own comfortable rhythm.
4. **Re-measure (45 s).** Keep breathing slowly while it measures again.
5. **Calm score.** A simple 0–100 relaxation index (formula below) with
   before/after breathing rate and HRV, plus an honest plain-language read.

No account. No analytics. No files written. Close the window and every trace
of the session is gone.

## Calm score formula

```
calm = 0.6 · rateScore + 0.4 · hrvScore        (when HRV is available)
calm = rateScore                                (breathing-rate-only mode)

rateScore = clamp01((baselineRate − endRate) / 4.0) · 100
hrvScore  = clamp01((endRMSSD − baselineRMSSD) / baselineRMSSD / 0.5) · 100
```

Dropping 4+ breaths/min maps to the full rate score; a +50% relative RMSSD
increase maps to the full HRV score. Both components clamp to [0, 100]. If
the SDK reports no HRV samples, the score falls back to rate-only and says so.
A session where you ended *faster* than you started scores 0 with an honest
note — the number is feedback, not a grade.

## Setup

Requirements: **Node.js >= 20** and a Presage API key (free developer credits)
from <https://physiology.presagetech.com/>. Platforms: macOS (arm64),
Windows (x64), Linux (x64/arm64, glibc >= 2.35).

```bash
git clone https://github.com/kindrat86/calm-breath.git
cd calm-breath
npm install
cp .env.example .env        # then paste your key into .env
npm start
```

Without an API key the app runs in **demo mode**: the full session flow with
a clearly-labelled synthetic signal (no camera, no SDK calls). Demo values
are generated by `src/sim.js` and are never presented as live data.

Run the unit tests (pacer logic, scoring, state machine, synthetic series):

```bash
npm test
```

Headless UI smoke test (demo mode, no camera needed — Linux/macOS with Xvfb):

```bash
npm run smoke
```

## Consent and Data Handling

**Camera consent.** The camera is used only after an explicit Start press on
a consent screen that states what is measured and why. A visible "camera on"
indicator and a Stop button are present for the whole session. Stopping (or
closing the window) releases the camera immediately. The app requests
video-only permission; microphone access is never requested and is denied by
the main process if asked for.

**Where processing happens.** Camera frames are processed locally inside the
app by the SmartSpectra SDK (in-process native library). Video frames are
**never** sent anywhere by Calm Breath, and the app makes no network calls
of its own — no analytics, no crash reporting, no accounts.

**Storage, sharing, retention, deletion.** Calm Breath stores nothing: no
video, no images, no metrics, no preferences. There is no database and no
filesystem write anywhere in the codebase (grep for yourself). Session values
live only in memory and are discarded when the session ends or the window
closes. Because nothing is stored, nothing is shared and nothing needs
deleting.

**SDK telemetry.** The SmartSpectra SDK can report "a small, aggregate
diagnostic summary once per session" (per the
[SDK Telemetry & Privacy documentation](https://smartspectra.presagetech.com/docs/telemetry-and-privacy)):
aggregate session statistics over the SDK's authenticated, TLS-pinned
channel, and it "never includes raw video or image frames, metric values,
file paths, user identifiers, or device IDs." Presage's privacy policy:
<https://api.physiology.presagetech.com/privacypolicy>.
**Calm Breath sets `enableTelemetry: false` by default**; the checkbox on
the consent screen opts you in to the aggregate summary if you want to
support SDK diagnostics. The API key in `.env` is sent only to Presage's
measurement service as part of SDK authentication. It is never committed to
the repo (`.env` is gitignored; `.env.example` contains only a placeholder).

**AI services.** None. No LLM, no cloud AI, no SmartSpectra LLM Insights —
every number on screen is computed locally from SDK measurements.

**Demo mode.** When no API key is configured, the app uses the synthetic
generator in `src/sim.js` and labels every screen "DEMO MODE — synthetic
data, no camera is used."

## Disclaimer

Calm Breath is a wellness and relaxation demo built for the Presage
SmartSpectra SDK Challenge. It is **not a medical device**, provides no
medical or health advice, and does not diagnose, treat, cure, or prevent any
condition. The calm score is informal self-relaxation feedback, not a
clinical measurement. If you have a breathing or cardiovascular condition,
or experience discomfort (some people feel light-headed when first
practicing slow breathing), stop and breathe normally. Sit down while using it.
